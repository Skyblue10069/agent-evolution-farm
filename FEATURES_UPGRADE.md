- Modular API layer: provider adapter registry for discovery, payments and FX.
- A/B strategy experiments with outcome-only measurement.
- Knowledge sharing from observed agent lessons.
- Cactus Needle mentor/self-model remains part of the system.
- Automatic recovery foundations through persisted checkpoints and unfinished-work persistence.
- Long-term learning journal.
- Generated owner dashboard at `dashboard.html`.

## Important boundaries
Agents may improve their strategy code only through the bounded self-modification system. Core safety, payment, accounting, authentication and orchestration code remains protected.

The farm never creates fake customers, fake sales, fake payment confirmations or fake external completion. Provider credentials and account eligibility remain external and must be legitimately authorized.
