# Agent Evolution — Maximum Evolution Layer

This upgrade adds the next evolution tier without inventing money, customers, payments, or external success:

- **Lineage replay:** compact per-cycle snapshots of top agents, parents, generations, outcomes, traits and work.
- **Adversarial guard:** scans agent plans/proposals and critical ledgers for prohibited/fraudulent patterns and can fail closed.
- **Opportunity intelligence:** clusters discovered opportunities and estimates novelty/saturation from observed data.
- **Maximum evolution lab:** records evidence-driven strategy choices and outcome history per agent.
- **Distributed farm manifest:** stable, deterministic population sharding for future isolated runners without concurrent shared-state mutation.

The distributed layer is intentionally a safe planner rather than pretending GitHub Actions can safely merge simultaneous writes to one JSON state file.
