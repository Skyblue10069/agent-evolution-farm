# Adaptive World

The environment evolves from observed simulation activity.

It tracks bounded conditions for competition, demand, opportunity supply,
resource pressure, volatility, and innovation. Opportunity scores receive a
separate environment component while preserving the original discovery score
as part of the blended score.

The world can generate simulation events such as innovation waves, resource
tightening, and volatile markets. These are conditions, not fake money,
customers, or payment records.

The environment runs before dispatch so agents must adapt to the current world.
It also persists a short history in `world_state.json`.
